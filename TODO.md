# Roadmap

- Complete canonical/raw terminal modes, process groups, and shell job control.
- Finish `poll`, named FIFOs, `/dev`, `/proc`, mounts, and storage recovery tests.
- Add shell command lists, variables, globbing, conjunctions, and background
  jobs; extend the existing pipelines and redirections with descriptor syntax.
- Expand and fixture-test the CraftOS and OpenOS compatibility matrices.
- Add account storage, salted password derivation, login, groups, and sessions.
- Add installers, upgrade rollback, recovery UI, and real-mod tests.
- Add hardware and networking capabilities after the terminal v1 is stable.
